# Review Notes

This folder contains my private practice notes on pull requests I have read.

I do not post these notes publicly on the PRs themselves. They are for me to build judgment. Each one is a structured assessment of a real PR, written as if I were the maintainer deciding whether to merge.

## Format

Each note is a separate `.md` file, named after the PR:

- `pypa-pip-pr-1234.md`
- `peterzty-markdown-reader-pr-294.md`
- etc.

## Why keep these

Writing review notes forces me to think carefully about code I did not write. It is the single best practice for building the judgment required for code review and patch evaluation work.
